Tenet Style Guide
File: style-guide.md
 Purpose: Define Tenet’s visual identity, UI system, and component patterns so that all UI/UX generated by engineers or Codex remains consistent, modern, minimal, and enterprise-ready.

1. Design Philosophy
Tenet’s UI direction is:
Telecom-inspired: structured, modular, signal-driven.


Minimal and monochrome: fewer colors, high clarity.


Enterprise-modern: clean edges, balanced whitespace.


Explainable and calm: low cognitive load, predictable patterns.


The interface must feel like infrastructure — precise, reliable, no noise.

2. Core Visual System
2.1 Color Palette
Tenet uses a monotone-first palette with a single accent color.
Primary Palette (Neutral Monochrome)
--gray-50: #F8F9FA


--gray-100: #F1F3F5


--gray-200: #E9ECEF


--gray-300: #DEE2E6


--gray-400: #CED4DA


--gray-500: #ADB5BD


--gray-600: #868E96


--gray-700: #495057


--gray-800: #343A40


--gray-900: #212529


Accent Color (Signal Blue)
Used sparingly for interactive elements and highlights.
--accent-blue-500: #3A7AFE


--accent-blue-600: #2F68D9


Status Colors
Success: #3FB983


Warning: #F2A93B


Error: #E5484D



2.2 Typography
Use a modern sans-serif family.
Font Family
Primary: Inter or Geist (preferred)


Fallbacks: system-ui, sans-serif


Type Scale (Tailwind tokens equivalent)
Display: 2xl / 3xl


Headings: xl / lg


Body: base / sm


Caption: xs


Font Weights
Regular: 400


Medium: 500


Semibold: 600


Bold: 700 (rarely used)


Rules:
Avoid overly heavy text.


Use 500 for most headings.


Body text should always be 400.



2.3 Spacing System
Use an 8-point grid.
Spacing tokens:
4px


8px


12px


16px


20px


24px


32px


Rules:
Use consistent vertical rhythm.


Default padding for components: 16px.



2.4 Border Radius
Rounded corners should feel modern but not playful.
Default: 8px


Cards/containers: 12px


Buttons: 8px


Inputs: 8px



2.5 Shadows
Use shadows sparingly.
Small shadow: rgba(0,0,0,0.04) 0px 1px 2px


Medium shadow: rgba(0,0,0,0.06) 0px 2px 4px


Avoid heavy shadows or glowing effects.

3. Layout & Structure
3.1 Page Layout
Tenet uses a three-part structure:
Sidebar navigation (left)


Top bar (header with search + profile)


Main workspace (content area)


Layout Rules:
Max content width: 1440px


Avoid full-width stretching.


Maintain generous whitespace around all modules.



3.2 Grid System
Use CSS grid or flexbox.


Default gap: 24px.


Dashboards use 2–3 column grids.


Forms use single-column with clear vertical flow.



4. Components
4.1 Cards
Padding: 24px


Background: white


Border: 1px solid var(--gray-200)


Radius: 12px


Shadow: small (optional)


States:
Hover: lighten border to --gray-300


Active: no animation; minimal movement



4.2 Buttons
Primary Button
Background: accent blue


Text: white


Radius: 8px


Padding: 8px 16px


Secondary Button
Background: white


Border: 1px solid gray-300


Text: gray-800


Ghost Button
Background: transparent


Text: gray-700


Rules
Don’t use more than one accent color button per view.


Primary button represents one clear action.



4.3 Inputs
Background: white


Border: 1px solid gray-300


Padding: 8px 12px


Radius: 8px


Focus: border accent-blue-500 + subtle shadow



4.4 Tables
Row height: 44–48px


Header font-weight: 500


Alternating row background: gray-50


Hover: gray-100


Focus selected row: accent-blue-500 left border (2px)



4.5 Tabs
Underline style


Active tab:


Border-bottom: 2px solid accent-blue-500


Font-weight: 500



5. Iconography
Use lucide-react icons


Line weight: 1.5px (consistent)


Icons should be monochrome unless communicating status


Rules:
Prefer outline icons


Rarely use filled icons


Keep icon size 16–20px



6. Motion & Transitions
Easing: ease-out or ease-in-out


Duration: 120–180ms


Subtle animations only; no bouncy or overshoot effects


Examples:
Fade + slide for modals


Slight opacity transition for hover



7. Dark Mode (Future)
Define palette but do not implement in v0.
Tone:
Dark gray surfaces


High contrast text


Blue accent remains the signal



8. Examples
8.1 Tenet Signature Look
Clean white background


Gray components


Blue accents for primary actions


Sharp grid alignment


Telecom-like structure (signal clarity)


8.2 What to Avoid
Overly colorful designs


Excessive shadows


Rounded chip-like UI (too playful)


Busy backgrounds


High-saturation accents everywhere



9. Implementation Notes

Use custom class names sparingly (keep design system unified)
